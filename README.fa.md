# ریموت فارسی Sony DAV-DZ950 / HBD-DZ950

پروژهٔ بومی Android با شناسهٔ `com.saleh.sonyremote` برای نمایش کنترل‌های مستند RM-ADU162 و ارسال مادون‌قرمز فقط با تعریف‌هایی که کاربر خودش تأیید کرده است. هیچ کد IR ساختگی یا حدس‌زده‌شده‌ای در پروژه وجود ندارد؛ همهٔ دکمه‌های عملکردی در نصب اولیه بدون کد هستند.

## واردکردن و ساخت APK

1. Android Studio به‌روز با JDK 17 را نصب کنید.
2. از **File → Open** پوشهٔ ریشهٔ این پروژه را باز کنید (پوشه‌ای که `settings.gradle.kts` دارد). اجازه دهید Gradle همگام‌سازی شود. AGP 8.13.2، Kotlin Android 2.2.21، Gradle 8.13، compileSdk 36 و minSdk 23 تنظیم شده‌اند.
3. برای ساخت: **Build → Build Bundle(s) / APK(s) → Build APK(s)**. خروجی معمولاً در `app/build/outputs/apk/debug/app-debug.apk` خواهد بود.
4. در این ZIP، Gradle Wrapper/JAR قرار نداده‌ایم؛ اگر Android Studio برای Gradle توزیع محلی/دانلود لازم داشت، Gradle 8.13 را در تنظیمات یا Android Studio انتخاب کنید. این پروژه در این محیط کامپایل نشده است.

## استفاده و تعریف کد

- صفحه گروه‌بندی شده و پیمایش‌پذیر است؛ کنترل‌های TV جدا از کنترل‌های خود دستگاه هستند. فهرست دکمه‌ها شامل powerها، ورودی‌ها، EQ/SURROUND، کارائوکه و MIC، منو، اعداد، صدا، جهت‌ها، رادیو و کنترل‌های DVD است.
- لمس معمولیِ دکمهٔ بدون کد فقط پیام می‌دهد و هیچ سیگنالی نمی‌فرستد. روی دکمهٔ هر عملکرد **لمس طولانی** کنید و فقط تعریف بررسی‌شدهٔ همان کلید را وارد کنید. داده در حافظهٔ خصوصی برنامه ذخیره می‌شود. پاک‌کردن متن و ذخیره، تعریف را حذف می‌کند.
- قالب‌های پذیرفته‌شده (اعداد ده‌دهی):
  - `SIRC:12:device:command` — device برابر ۰ تا ۳۱، command برابر ۰ تا ۱۲۷.
  - `SIRC:15:device:command` — device برابر ۰ تا ۲۵۵، command برابر ۰ تا ۱۲۷.
  - `SIRC:20:device:command:extended` — device برابر ۰ تا ۳۱، command برابر ۰ تا ۱۲۷، extended برابر ۰ تا ۲۵۵.
  - اختیاری: `RAW:frequency:on,off,on,off,...`؛ تعداد مدت‌ها زوج، همگی مثبت، شروع با on و کمتر از ۲ ثانیه. فرکانس باید در صورت گزارش بازه‌های پشتیبانی دستگاه داخل یکی از بازه‌ها باشد.
- فرستندهٔ Consumer IR با فرکانس اسمی 40,000 Hz کار می‌کند. فریم‌های SIRC با سربرگ 2400/600µs، دادهٔ LSB-first (markهای 600/1200µs و فاصلهٔ 600µs) و سه فریم با فاصلهٔ شروع حدود 45ms ساخته می‌شوند. الگوی SIRC کامل کمتر از ۲ ثانیه است. پیاده‌سازی اعتبارسنجی ساختاری می‌کند، اما معتبر بودن یک زوج device/command را برای دستگاه واقعی تضمین نمی‌کند.
- `SHIFT` فقط وضعیت دیداری رابط را عوض می‌کند؛ به‌تنهایی سیگنال IR نمی‌فرستد و ترکیب‌های بنفش ناشناخته را به عملکرد فرضی تبدیل نمی‌کند.

## منبع کد مطمئن و محدودیت‌ها

گوشی دارای IR blaster فقط **ارسال** می‌کند و معمولاً نمی‌تواند ریموت را بشنود یا کد آن را یاد بگیرد. برنامه هیچ مجوز اینترنتی ندارد. برای به‌دست‌آوردن کدهای قابل اتکا، RM-ADU162 سازگار را به‌سمت یک گیرندهٔ IR جداگانه (مثلاً گیرنده/تحلیلگر IR متصل به سخت‌افزار ثبت‌کننده) بگیرید، فریم را چند بار ضبط و پروتکل SIRC، تعداد بیت، device و command را رمزگشایی کنید؛ یا از دیتابیس/مستند معتبرِ کدهای SIRC/Pronto استفاده و کد معادل را مستقل تأیید کنید. RAW باید الگوی زمانی mark/space میکروثانیه‌ای دقیق باشد، نه حدس از نام دکمه. قبل از استفاده، کد هر دکمه را با عملکرد درست روی دستگاه بیازمایید.

مدل تلویزیون مشخص نیست؛ دکمه‌های **TV POWER** و **TV INPUT** ممکن است از کدهای دیگری (و حتی پروتکل/مدل دیگری) استفاده کنند. آن‌ها عمداً از کلیدهای دستگاه DAV جدا هستند و خودکار با کد دستگاه سینمای خانگی پر نمی‌شوند. سازگاری نهایی به فرستندهٔ IR گوشی و دریافت کد صحیح توسط دستگاه بستگی دارد.
